# 插件兼容与验证范围

以下是桥接 v0.3.16 针对 AstrBot 4.29.1 的已审阅组合。只列源码和虚构测试；不分发实际用户配置、群消息、登录信息或模型。每份补丁只适用于其 `baseline.json` 对应文件，应用前备份并执行 `git apply --check`。已改过的文件应按差异适配，不要强行覆盖。

| 插件 / 已检验版本 | 接入方式 | 修复或配置条件 |
| --- | --- | --- |
| 本机 Codex 桥接 0.3.16 | 默认聊天、工具循环、图片/视频、语音/翻唱、角色与成员设置 | 各媒体能力独立开关；RVC、FFmpeg、TTS 需真实配置 |
| AstrBot OneBot 4.29.1 | 点歌、TTS、翻唱共用的语音发送 | [保留压缩音频](astrbot_onebot_audio/README.md)，避免歌曲展开为 WAV 后超过 NapCat 的消息上限；这是框架补丁，需另行应用 |
| 我想听歌！0.1.3 | 搜歌、发歌、给桥接提供翻唱候选 | [链接与 Windows 登录补丁](listen_music/README.md)；B 站风控仍可能返回 HTTP 412 |
| 点歌 2.2.0 | 自然语言点歌/歌词、命令、允许的平台为翻唱提供备用音源 | [平台别名与下载限制](music/README.md)；远程卡片/音频获取仍依赖平台及 NapCat |
| 链接解析 1.5.7 | 原有消息处理器 | 桥接为音乐请求保留模型入口；普通分享继续解析，不保证所有外部站点可用 |
| 表情包管理器 5.2.3 | 分类标记、回复配图、Codex 识图采集 | 图库需有可用图片；语义向量检索需单独配置，关闭它不影响分类配图 |
| 表情包小偷 3.1.6 | Codex 识图采集、群内检索/发送 | [双表情插件协调](stealer/README.md)避免同轮自动重复配图；任意地址采集工具不向普通群员开放 |
| LivingMemory 2.7.1 | 总结、群共享记忆、只读回忆工具 | [群范围补丁](livingmemory/README.md)及独立 Embedding 模型，保留会话/人格过滤 |
| 自学习 4.3.1 | 表达学习、社交上下文、个人设置审批 | [累计适配及角色稳定补丁](self_learning/README.md)；后台建议仍需审批 |
| 主动消息 1.2.6 | 群级计时、常规模型/工具/发送流程 | [兼容补丁](proactive_chat/README.md)；可选沉默后发言或不受聊天活动影响的随机间隔模式，停用插件停止定时工作 |
| 专业戳一戳 2.1.1 | 戳事件回复、群内受限工具、可选定时任务 | [定时目标、缺失命令与失败反馈修复](pokepro/README.md)；示例目标必须替换，未配置时关闭定时任务 |
| 群分析总结 5.8.0 | `llm_generate`、数组 JSON、可选流式、查询本群报告 | 自动日报需另配群名单、时间及最低消息量，空名单不会产生自动日报 |

AstrBot 内置管理插件与 `builtin_commands` 也保留原权限；全局 `disable_builtin_commands=true` 时 `/help` 等会被框架跳过，桥接自己的 `/new` 独立工作。不要为了启用普通聊天而放开全部管理命令。

验证包含真实插件处理器、AstrBot 执行器、虚构平台事件和假发送器；媒体下载另使用回环 HTTP 服务验证超时、大小和取消清理，Windows 账户保存使用临时虚构凭据核验 ACL。模型格式和角色表达另有真实 Codex 隔离调用验证。自动测试不向 QQ 发消息，因此重启后仍需在实际会话检查消息呈现；外部接口、登录状态、平台权限及音色听感不由源码测试保证。

本仓库不自动安装/启用所有可选功能。变更插件开关、群名单或定时发送配置应按自己的用途选择；不提供通用 Embedding 或 STT 接口。各衍生补丁的许可和上游来源见其子目录。
