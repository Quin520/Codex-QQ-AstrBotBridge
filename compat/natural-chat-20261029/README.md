# 自然聊天与主动消息适配

桥接 v0.4.1 增强日常聊天的性格、立场和连续性。它沿用已有 AstrBot 人格，不替换成员的称呼、相处方式、已发生的事情或长期记忆；学习与好感度审批仍按各自原配置执行。

## 配置方法

在“QQ 角色与群记忆桥接”中开启“自然聊天与角色表达”：

| 选项 | 用法 |
| --- | --- |
| 聊天表达档位 | 自然群友、角色感更鲜明、简短克制。角色感更鲜明适合有明确偏好、会回嘴的角色。 |
| 括号动作与旁白 | 普通 QQ 群聊建议“尽量不用”；明确的场景扮演仍可以描写动作。 |
| 固定角色表达约定 | 写长期口吻与原则，不重复整份人格。例如“表达观点时先选自己认同的一边，说具体理由；不默认正反各一段”。 |
| 角色说话范例 | 只写少量虚构的表达样例，不当作真实共同经历；可随时自行修改。 |
| 每个成员的设置 | 放这个人的称呼、关系、边界和确认过的事情，优先于自动好感度和心理推测。 |

角色可以有鲜明主观判断。傲娇角色被纠正后可以找台阶、不主动道歉、直接接上正确内容，不必每次作认错检讨；这不授权坚持已知错误或虚构事实。明确要求全面比较时仍比较，认真求助时仍给有用答案。没检索到记忆表示“这里没记到”，不能因此断言对方从未说过。

为减少表达冲突，范例不要同时要求“叫停玩笑就停止”和“叫停后继续嘲讽”。人格、成员事实与虚构范例分别保存即可，不需要清空会话或执行 `/new`。

## 主动消息

本目录的补丁在群聊随机间隔模式中增加“避免主动发言复读”，AstrBot 配置页与主动消息独立面板共用配置字段。

- 只记录本会话最近 6 小时内、最多 6 条确认发送成功的主动文字；失败发送不记入，重启后可继续使用。
- 将最近发言提供给模型避免重复；完全重复或长句几乎照抄的纯文字会跳过这一轮，照常安排下次，不增加未回复次数。
- 不同群的记录独立；媒体消息和已由工具送出的内容不受这项文字拦截影响。变化的数值、中文时间和否定词不会仅因整体相似就被拦截。
- 这是保守的文字去重，不是语义分类器；换一种说法谈同一件事仍可能通过。

主动发言通常适合文字。若不希望每轮都变语音，在主动消息的群聊语音设置里关闭“启用 TTS”；桥接的 `send_voice`、角色音色和翻唱仍可使用。主动提示词可允许在祝福等适合的场景选语音，不必同时强制发送语音和重复文字。

将平台流水提示词写成“理解最近真实话题”，不要固定要求“冷场破冰、提出开放问题”。本补丁不改变随机间隔、静默时段和无人回应上限，继续用自己的设置。

自学习中如需让情绪跨重启保持稳定，可关闭 `Mood_System_Settings.enable_startup_random_mood`；每日情绪变化与事件学习仍保留。本次不改学习审批开关，也不清理已有审批。

## 应用与回滚

这是**增量补丁**，基线为主动消息 v1.2.6 **已经应用** [20261029 累计适配](../updates-20261029/README.md)后的源码，不能直接用于上游原版。`manifest.json` 列出变更文件的 LF 标准化前后校验值与补丁 SHA-256。

1. 备份源码、配置和数据，先对匹配基线执行 `git apply --check astrbot_plugin_proactive_chat.patch`。
2. 应用补丁，保留自己已有的配置。桥接升级到 v0.4.1。
3. 停止再启动 AstrBot；NapCat 可保持运行。桥接与主动消息配置页应出现上述选项。
4. 回滚时停止 AstrBot，恢复这次变更的源码与配置。本次没有数据库迁移，避免用旧备份覆盖更新后产生的聊天。

媒体指令按经过权限过滤后实际存在的工具生成；电脑访问权限、媒体功能开关与失败处理继续由原执行校验控制。群公共上下文额外提供本群最近互动时间，解析文章与视频摘要不算新的成员发言。

## 验证

桥接 365 项回归、主动消息 57 项回归通过，覆盖失败发送、重启历史、群隔离、重新调度、媒体交付和开关行为。补丁通过真实应用后的文件校验。使用虚构人物和对话进行了 API 小样本验证，涵盖吐槽、认真建议、叫停玩笑、未知记忆、讨厌成员、关系冲突、主观观点与纠错；未向 QQ 发送测试消息。模型措辞仍有随机性，样例不代表每次回复的保证。

此目录不包含实际 QQ 号、群成员设定、聊天、账号凭据或本机配置。
